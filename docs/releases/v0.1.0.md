The first release of **autoproton**: it picks the best Proton version and launch options for your
Steam games from ProtonDB reports, and saves them to Steam with a backup you can undo.

## Get it

1. Download `autoproton-0.1.0-x86_64.AppImage` below.
2. Make it executable: right-click → Properties → "Allow executing as program", or `chmod +x autoproton-0.1.0-x86_64.AppImage`.
3. Double-click it.

It runs on 64-bit Linux with glibc 2.35 or newer: Ubuntu 22.04+, Debian 12+, Fedora, Arch, openSUSE and SteamOS.
There's nothing to install. **On the Steam Deck**, run it from Desktop Mode.

## What's in it

- **Your installed games**, each with its ProtonDB rating.
- **A recommended Proton version** (native, Proton, Proton Experimental or GE-Proton), with the report counts behind it.
  - Recent reports from your kind of device count most.
- **Launch options to tick on or off.**
  - Common fixes are ticked for you.
  - Personal extras (overlays, HDR) are offered but never forced.
  - Anything unsafe from a report is filtered out.
- **The exact before and after**, shown before anything is saved.
  - autoproton closes Steam if it's running, since Steam overwrites these settings when it exits.
- **GE-Proton** is downloaded from its official release and checked against its published checksum, but only when you choose it.
- **Backups before every change**, and **History** to undo any of them.
  - The same AppImage works from a terminal too: `./autoproton-0.1.0-x86_64.AppImage --cli --help`.

## Before you rely on it

This is a first release. The automated tests use a fake Steam folder and real ProtonDB data. They haven't
yet been run against every real Steam setup, so the [manual test checklist](https://github.com/gamesensicals/autoproton/blob/v0.1.0/docs/MANUAL_TEST.md) lists what to check on yours. Every change is
backed up and can be undone, and the first backup of each Steam file is kept forever.

Ratings and reports come from [ProtonDB](https://www.protondb.com) (ODbL). autoproton isn't affiliated with
Valve, ProtonDB or GloriousEggroll.
